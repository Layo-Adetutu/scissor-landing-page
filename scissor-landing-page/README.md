# Scissor Landing Page

Responsive HTML and CSS recreation of the Scissor URL shortener landing page assessment.

## Run locally
Open `index.html` in your browser. No build tools are required.

## Deploy
Push this folder to a **public** GitHub repository, then import the repository into Vercel. The project uses `index.html` at the root, so no build command is required.

## Notes
The URL form is a front-end demonstration. A real shortening result requires a backend/API. FAQ items use native HTML `<details>` and `<summary>`.
